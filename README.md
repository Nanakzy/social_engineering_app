# Social Engineering Training App

## Setup Backend
1. cd backend
2. python3 -m venv venv
3. source venv/bin/activate  # Windows: venv\Scripts\activate
4. pip install -r requirements.txt
5. Create a .env file with your Unsplash API key
6. Run: python app.py

## Setup Frontend
1. cd frontend
2. npm install
3. npm start
